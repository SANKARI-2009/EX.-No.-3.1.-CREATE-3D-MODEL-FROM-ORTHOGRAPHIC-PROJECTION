# EX. No.3.1. CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION
## DATE:

## AIM:
To create a 3D model from given orthographic projection.

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
STEP 1: Open a New Design
     Open Autodesk Fusion 360 on the computer and wait until the application is fully
loaded. Select the Design workspace and click on File → New Design to open a new
design file. Make sure that the Solid toolbar is displayed before starting the modelling
process.

STEP 2: Start the Sketch Command
        Click on Create Sketch from the Solid toolbar. The three reference planes (XY, XZ
and YZ) will appear on the screen. Select the appropriate plane based on the given
orthographic projection to begin drawing the sketch.

STEP 3: Create the Required Sketch
Select the necessary sketching tools from the Sketch toolbar, such as Line,
Circle, Arc, Rectangle and Polygon, according to the given drawing. Draw the
required geometrical shapes by selecting the appropriate starting and ending points.
Enter the specified dimensions using the Sketch Dimension (D) command. Make sure
that the sketch is properly aligned and matches the given orthographic views.

STEP 4: Modify the Sketch
        Use the sketch modification tools available in the toolbar to make the necessary
changes to the drawing. Select commands such as Trim, Extend, Mirror, Move and
Delete to modify the sketch. Remove unwanted lines, adjust the required shapes and
maintain proper alignment. Check that the sketch represents the required profile before
proceeding.

STEP 5: Inspect and Verify the Dimensions
         Select the Inspect → Measure command from the toolbar to check the dimensions
of the sketch. Select the required lines, edges or points to measure their lengths and
distances. Compare the measured values with the dimensions given in the orthographic
projection. Make the necessary corrections to ensure dimensional accuracy.

STEP 6: Finish the Sketch
    After completing the sketch and checking all the dimensions, click on Finish
Sketch from the toolbar. The sketching environment will close, and the completed 2D
profile will be displayed in the Design workspace. Check the sketch once again before
converting it into a 3D model.

STEP 7: Convert the Sketch into a 3D Model
       Select Solid → Create → Extrude from the toolbar. Click on the required closed
sketch profile and enter the extrusion distance according to the given drawing. Check
the direction and preview of the extrusion. Select the appropriate operation, such as
New Body or Join, depending on the model requirement. Click OK to convert the 2D
sketch into a 3D solid model.

STEP 8: Complete the 3D Model
      Continue creating the remaining features by selecting the required faces and
using the Sketch and Extrude commands. Add the necessary geometrical features
according to the given orthographic projection. Rotate the model using the ViewCube
and observe it from the front, top, side and isometric views. Verify that the completed 3D
model matches the given drawing.

STEP 9: Create a Drawing Sheet
      After completing the 3D model, navigate to Design → Drawing → From Design to
create a new drawing sheet. Select the required drawing standard as ISO and choose
the appropriate sheet size and units. Click OK to open the drawing workspace.

STEP 10: Generate Orthographic Views
     Select Base View from the Drawing toolbar and place the main view on the drawing
sheet. Choose the required orientation and scale. Use the Projected View command to
generate the top, front and side views from the base view. Arrange the views properly
according to the ISO projection method specified for the drawing.

STEP 11: Add Dimensions and Save the Drawing
           Select the Dimension command from the drawing toolbar and add the required
dimensions to the orthographic views. Check that all the views are properly aligned and
the dimensions are clearly visible. Add the necessary drawing details and save the
completed drawing sheet. The drawing can also be exported as a PDF if required.
